원저작자와 이용자는 본 약관 위반으로 인한 손해액의 입증이 곤란함을 감안하여, 다음 각 호

할 수 있다.

본 자료에 삽입된 디지털 식별자(스테가노그래피, Hash값 등)를 통해 최초 유출자가 특정된 경

제2항에 명시된 손해배상 예정액은 본 약관 시행일을 기준 시점으로 하여, 한국은행이 공표하

조정 방식: 청구 시점의 예정액 = 약관 시행 시 예정액 × (청구 시점 CPI ÷ 시행일 기준 CPI)
조정은 매년 1월 1일을 기준으로 갱신되며, 한국은행 경제통계시스템(ECOS, 
https://ecos.bok.or.kr) 공표 수치를 기준으로 한다.
