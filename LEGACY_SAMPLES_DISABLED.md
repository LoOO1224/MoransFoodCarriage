# Disabled Legacy Samples

These files are intentionally kept as reference material but excluded from Unity compilation.
Their `.cs.disabled` suffix is the visible marker.

The active instructor sample versions remain under the `DN_*` folders.

Disabled legacy files:
- `Assets/Scripts/2DPlayer/DaniTech_2DEnemy.cs.disabled`
- `Assets/Scripts/2DPlayer/DaniTech_2DPlayer.cs.disabled`
- `Assets/Scripts/Common/DaniTechGameObjectManager.cs.disabled`
- `Assets/Scripts/DN_DataDriven/GameData.cs.disabled`
- `Assets/Scripts/DN_DataDriven/GameDataManager.cs.disabled`
- `Assets/Scripts/DN_DataDriven/GameUtil.cs.disabled`
- `Assets/Scripts/DN_UI/DanITechGameTestUI.cs.disabled`

To restore one later, first check that no active class has the same name.
Then rename both the file and its `.meta` file to remove `.disabled`.
